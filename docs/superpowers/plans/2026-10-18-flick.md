# Flick Implementation Plan

> **For agentic workers:** Executed inline in the authoring session (user asked for autonomous execution). Steps use checkbox (`- [ ]`) syntax.

**Goal:** Mobile-first memo-first task app with flick status changes, Google login, Workers AI helpers, deployed on Cloudflare.

**Architecture:** One Cloudflare Worker serves a Hono API under `/api/*` and a Vite-built React SPA as static assets. D1 stores users, sessions, tasks and AI usage. The client is local-first (localStorage cache + outbox) so the memo input works instantly.

**Tech Stack:** TypeScript, Hono, D1, Workers AI, Arctic (Google OIDC), React 19, Vite, Motion, vite-plugin-pwa, Vitest + @cloudflare/vitest-pool-workers, Playwright.

**Spec:** `docs/design.md`

## Global Constraints
- Statuses: `todo` → `doing` → `done`. Right flick = next, left flick = previous, left on `todo` = archive (undoable).
- No marketing copy anywhere. Login screen = app name + "Google でログイン" only.
- Google is the only login method. `/api/auth/dev-login` exists only when `DEV_AUTH === "1"` (set in `.dev.vars`, never in production).
- White-based liquid glass; respect `prefers-reduced-motion`.
- AI daily limit per user: `AI_DAILY_LIMIT` (default 50).
- No secrets in the repo. `GOOGLE_CLIENT_SECRET` is a Wrangler secret.
